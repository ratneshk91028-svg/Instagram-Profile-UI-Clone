# Instagram-Profile-UI-Clone

A backend-driven web application designed to practice dynamic routing, data parsing, and server-side rendering using template engines.

✨ **Features**
**Dynamic Profiles:** Parses route parameters to generate custom user profile views.
**Server Logic**: Generates random data on the server side and renders it directly in the UI.
**JSON Integration**: Configured to read, manage, and display data fetched from local JSON structures.
**Robust File Paths**: Uses built-in path utilities to ensure reliable directory resolution.

🛠️ Tech Stack 
**Runtime**: Node.js
**Framework**: Express.js
**Templating**: EJS (Embedded JavaScript)
**Development Tool**: Nodemon (for hot reloading)

🚀 Setup & Installation
1. Clone this repository: git clone <your-repo-link>
2. Install the required dependencies: npm install
3. Run the application: nodemon index.js
4. Open your browser and navigate to: http://localhost:8080/
